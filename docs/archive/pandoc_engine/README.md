# Pandoc Engine Provenance

This directory records that the formal Pandoc conversion skeleton was absorbed from the
external `tex2docx_pandoc` repository during the `rebuild-platform-around-capability-matrix`
change.

Absorbed into code:

- template configuration and detection
- preprocessors
- Lua filters
- orchestrator and runner skeleton

Not copied as code:

- ad-hoc build outputs
- machine-specific backup files
- cache directories
